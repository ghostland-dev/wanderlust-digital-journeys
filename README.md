# VoyageÉlite

Online travel agency for tailor-made trips.

## Features

- Trip catalogue and details
- Custom trip requests
- Client area and back office
- Blog

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/wanderlust-digital-journeys.git
cd wanderlust-digital-journeys
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
